# Browser Games — School Project

[🌐 Open live website](https://bur-maks.github.io/browser-games-school-project/)

A school web project originally started in the 10th grade and later expanded in the 11th grade.

The project is a small multi-page website about browser games, their history, the Flash era and browser game development.

It also includes a playable **Snake game written in JavaScript using HTML Canvas**.

---

## Features

- Multi-page website
- Navigation between pages
- Custom CSS styling and hover effects
- Information about browser games and Flash
- JavaScript Snake game
- Keyboard controls
- Score counter
- Random food generation
- Wall collision detection
- Self-collision detection

---

## Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas

No frameworks were used.

---

## Snake Game

The Snake game is implemented using JavaScript and the HTML Canvas API.

### Controls

- ↑ Up
- ↓ Down
- ← Left
- → Right

The game includes snake movement, food spawning, score tracking and collision detection.

## Project history

This project was originally created as a school project.

I started working on it in the **10th grade** and later expanded it into a larger website in the **11th grade**.

The project is intentionally kept close to its original form to preserve it as one of my early programming projects.
